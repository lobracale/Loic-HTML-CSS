Introduction à HTML

HTML (HyperText Markup Language) est le langage utilisé pour structurer les pages web à l'aide de balises et d'attributs.

Il permet notamment de définir les titres, paragraphes, liens, images, listes et formulaires d'une page.

Les balises HTML

Quelques balises courantes :

  • <h1> à <h6> : titres
  • <p> : paragraphe
  • <a> : lien
  • <img> : image
  • <div> : conteneur

Attributs HTML

  • class : associe une classe CSS
  • id : identifiant unique
  • src : source d'une ressource
  • href : destination d'un lien

Exemple de code HTML

<!DOCTYPE html>
<html lang="fr">
  <head>...</head>
  <body>
    <h1>Bienvenue</h1>
  </body>
</html>

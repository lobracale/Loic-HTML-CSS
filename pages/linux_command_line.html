Commandes Linux

Voici un mémento des principales commandes Linux utilisées en SISR.

CommandeDescriptionExemple d'utilisation
lsListe les fichiers et dossiersls -l
cdChange de répertoirecd /home/user
pwdAffiche le répertoire courantpwd
mkdirCrée un répertoiremkdir documents
rmdirSupprime un répertoire vidermdir documents
touchCrée un fichier videtouch fichier.txt
cpCopie un fichier ou dossiercp fichier.txt sauvegarde.txt
mvDéplace ou renommemv ancien.txt nouveau.txt
rmSupprime un fichierrm fichier.txt
catAffiche le contenu d’un fichiercat fichier.txt
grepRecherche du textegrep "mot" fichier.txt
chmodModifie les permissionschmod 755 script.sh
sudoExécute une commande avec les droits administrateursudo apt update
aptGère les paquets Debian/Ubuntusudo apt install nginx
manAffiche le manuel d’une commandeman ls
